## 🧪 Methodology

1. Review official CVE records and vendor advisories.
2. Identify affected software versions and prerequisites.
3. Study the vulnerability and its root cause.
4. Reproduce the issue only in an authorized environment.
5. Document verified impact, references, and remediation.

## 🛡️ Responsible Research

All testing should be conducted on systems I own or have explicit permission to assess. Research claims will be supported by evidence and reliable references.
